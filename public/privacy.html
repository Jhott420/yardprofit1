Privacy Policy

Shorts Autopilot · Last updated 8 November 2026

Shorts Autopilot is a private tool used by the operator of YardProfit to create short videos and publish them to the operator's own YouTube channel. It is not offered to the public.

What the app accesses

When the channel owner signs in with Google, the app requests access to the YouTube Data API and YouTube Analytics API for that owner's account. It uses this access only to:

  • upload videos, thumbnails and captions to the owner's own channel;
  • update titles, descriptions, tags and playlists of those videos;
  • post a comment on the owner's own videos;
  • read view and performance statistics for the owner's own channel.

How data is stored

The Google sign-in token is stored privately on the machine that runs the tool and is used only to perform the actions above. The app does not collect personal information about viewers or any other users, does not sell or share data with third parties, and does not use Google user data for advertising.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time from the Google Account security settings at myaccount.google.com/permissions.

Contact

Questions about this policy can be sent to the support email shown on the app's Google sign-in screen.
